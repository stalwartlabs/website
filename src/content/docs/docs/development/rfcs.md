Stalwart implements a large number of internet standards, and this page lists them for developers and administrators who need to know whether a particular specification is supported. The list covers both published RFCs and Internet-Drafts, the working documents that may later become RFCs, grouped by protocol. The JMAP capabilities that correspond to these specifications are listed separately, in [JMAP capabilities](/docs/http/jmap/capabilities).
