## Fields


##### `description`

> Type: <code>String</code> · required
>
> Description of the certificate authority


##### `certificate`

> Type: <code>Text</code> · required
>
> CA certificate in PEM format


##### `enable`

> Type: <code>Boolean</code> · default: `true`
>
> Whether the certificate authority is trusted


##### `subject`

> Type: <code>String</code> · server-set
>
> Subject of the CA certificate, taken from the certificate itself


##### `expiresAt`

> Type: <code>UTCDateTime</code> · server-set
>
> Expiration date of the CA certificate, taken from the certificate itself



## JMAP API

The SmimeTrustAnchor object is available via the `urn:stalwart:jmap` capability.


### `x:SmimeTrustAnchor/get`

This is a standard [`Foo/get`](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.


This method requires the `sysSmimeTrustAnchorGet` [permission](/docs/ref/permissions).

```bash
curl -X POST https://mail.example.com/jmap/ \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SmimeTrustAnchor/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```



### `x:SmimeTrustAnchor/set`

This is a standard [`Foo/set`](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

Supports the following operations in a single call: create, update, destroy.



#### Create

This operation requires the `sysSmimeTrustAnchorCreate` [permission](/docs/ref/permissions).

```bash
curl -X POST https://mail.example.com/jmap/ \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SmimeTrustAnchor/set",
          {
            "create": {
              "new1": {
                "certificate": "Example",
                "description": "Example"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```


#### Update


## CLI

`stalwart-cli` wraps the same JMAP calls. See the [CLI reference](/docs/management/cli/) for installation, authentication, and general usage.


### Fetch

```sh
stalwart-cli get SmimeTrustAnchor id1
```


### Create

```sh
stalwart-cli create SmimeTrustAnchor \
  --field description=Example \
  --field certificate=Example
```


### Query

```sh
stalwart-cli query SmimeTrustAnchor
```


### Update

```sh
stalwart-cli update SmimeTrustAnchor id1 --field description='updated value'
```


### Delete

```sh
stalwart-cli delete SmimeTrustAnchor --ids id1
```
