Constants available in expression contexts that reference `KeyTrustConstant`.

| Constant | Description |
|---|---|
| `manual` | Added by an administrator |
| `verified` | Verified through a CA chain or DNSSEC |
| `discovered` | Fetched through WKD or keys.openpgp.org |
| `harvested` | Learned from authenticated mail without a CA chain |
| `unverified` | Unverified |
