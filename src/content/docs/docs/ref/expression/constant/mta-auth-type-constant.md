Constants available in expression contexts that reference `MtaAuthTypeConstant`.

| Constant | Description |
|---|---|
| `login` | SASL LOGIN mechanism |
| `plain` | SASL PLAIN mechanism |
| `xoauth2` | SASL XOAUTH2 mechanism, offered only over TLS |
| `oauthbearer` | SASL OAUTHBEARER mechanism, offered only over TLS |
