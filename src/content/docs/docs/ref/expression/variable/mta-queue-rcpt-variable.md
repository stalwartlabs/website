Variables available in expression contexts that reference `MtaQueueRcptVariable`.

| Variable | Description |
|---|---|
| `rcpt` | Recipient address; the domain is lowercase, the local part keeps its case |
| `rcpt_domain` | Domain of the recipient |
| `recipients` | List of all recipient addresses of the message |
| `sender` | Envelope sender (return path), empty for bounces |
| `sender_domain` | Domain of the envelope sender, empty for bounces |
| `priority` | Message priority (number, from -9 to 9, 0 when not set) |
| `retry_num` | Number of delivery attempts made so far for the recipient |
| `notify_num` | Number of delay notifications sent so far for the recipient |
| `expires_in` | Seconds until the message expires, or remaining attempts when expiry is set by attempt count; 0 once expired |
| `last_status` | Delivery status of the recipient: Scheduled, Delivered, Temporary Failure or Permanent Failure, followed by details |
| `last_error` | Type of the last error: none, dns, unexpected-reply, connection, tls, dane, mta-sts, rate, concurrency or io |
| `queue_name` | Name of the queue holding the message |
| `queue_age` | Seconds since the message entered the queue |
| `received_from_ip` | IP address the message was received from |
| `received_via_port` | Local port the message was received on (number) |
| `source` | How the message entered the queue: authenticated, dmarc_pass, unauthenticated, dsn, report, autogenerated or unknown |
| `size` | Message size in bytes |
