Some settings belong to no single protocol and no single domain, because they shape how the whole server behaves. This section collects them. They decide which ports the server listens on and how it secures the connections that arrive there with TLS. They also decide how the server protects itself from clients that abuse it, and which DNS resolver and DNS providers it relies on. Further settings control how mail, calendar and contacts clients discover the server, and the license that enables the Enterprise features.

The pages are grouped by the part of the server they affect.
